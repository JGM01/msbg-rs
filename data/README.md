# Bunny fixtures

These PLY files come from the Stanford University Computer Graphics Laboratory.
They are included for tests, reconstruction examples, and benchmarks.

- `bun_zipper.ply`: 35,947 vertices and 69,451 faces.
- `bun_zipper_res2.ply`: 8,171 vertices and 16,301 faces.

The files were copied without changes from the
[MSBG development fork at revision 5aed13c](https://github.com/JGM01/MSBG/tree/5aed13c0674f141359bf764f2e57752372a6a67f/data).
The original research implementation is [tum-pbs/MSBG](https://github.com/tum-pbs/MSBG).
